## 使用房间列表

1. 登录 Cloud，并绑定至少一个已通过验证的游戏账号；按提示完成密码设置等账号准备步骤。
2. 打开 [房间匹配](/rooms)。默认显示所有地区、等待中且有空位的房间。
3. 根据需要选择地区、状态和“有空位”。自定义服务器也可以从自定义地区中查找。
4. 核对房间的游戏版本、服务器、地图、聊天语言与人数。列表按模组版本分组，避免混淆不同版本。
5. 点击房间码复制。在 Among Us 中选择同一服务器，输入房间码加入。

Cloud 展示的是房主主动分享的房间，不是全部在线房间。房间匹配提供查找和复制功能，不会替你启动游戏或自动选择服务器。

## 服务器与版本

房间码必须与对应服务器配合使用。卡片中若提供服务器地址，可以点击打开或复制；未提供地址时，需要向房主确认连接方式。

先匹配 Among Us 游戏版本。房主使用 TOHEE 时，普通玩家通常可以使用原版加入；特殊服务器、人数或模式是否支持该客户端，以房主规则与当前模组版本为准。列表显示的模组版本说明房主环境，不是要求所有玩家都安装同一模组。

## 刷新与状态

页面可见时通常每 10 秒自动刷新，也可以点击“立即更新”。切到后台时自动查询会暂停；获取失败时会退避重试。页面显示数据时间，以便判断信息是否新鲜。

如果刷新失败但仍有上次成功的数据，页面会保留它并提示“无法获取最新状态”。此时人数、空位和房间状态可能已经变化。“等待中”不保证加入时仍然开放。

## 找不到或进不去

清除筛选条件，检查是否选错地区；确认游戏版本和服务器相同。房间可能已满、已开始、关闭或停止分享。空列表也可能只是没有房主分享，不能据此判断游戏服务器是否故障。

## Use the room list

1. Sign in to Cloud and link at least one verified game account. Complete any required password or account setup.
2. Open [Find a room](/rooms). The default view shows Lobby rooms from all regions with available slots.
3. Select a region, status and Available slots as needed. Custom regions can include custom servers.
4. Check the game version, server, map, chat language and player count. Rooms are grouped by mod version to distinguish host environments.
5. Click the room code to copy it. Select the same server in Among Us and enter the code to join.

Cloud lists rooms their hosts choose to share, not every online room. Matchmaking helps you find and copy codes; it does not launch the game or select a server for you.

## Servers and versions

A room code must be used on its matching server. If the card provides an address, open or copy it as offered. If no address is available, ask the host how to connect.

Match the Among Us game version first. Ordinary players can generally join a TOHEE host using unmodded Among Us. Support for particular servers, player counts and modes depends on the host's rules and current mod version. A listed mod version describes the host; it does not mean every player must install that mod.

## Refresh and status

While visible, the page normally refreshes every 10 seconds. You can also use Refresh now. Automatic checks pause in the background and retry with a delay after failures. The displayed data time helps you judge freshness.

If a refresh fails after an earlier success, the page retains those results and warns that it could not get the latest status. Counts, open slots and room status may have changed. Lobby status does not guarantee that a room will still be open when you join.

## Missing rooms or failed joins

Clear filters and check the region. Confirm that your game version and server match. A room may be full, started, closed or no longer shared. An empty list may simply mean no hosts are sharing; it does not establish that the game server is down.
