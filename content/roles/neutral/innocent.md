## 冤罪师

冤罪师可以使用击杀按钮栽赃任意玩家。被栽赃的目标会立即杀死冤罪师。若目标在会议中被投票放逐，冤罪师获胜；若目标是内鬼，只有开启对应选项后冤罪师才会获胜。

小丑、处刑人和冤罪师可以同时获胜。

## 设置

- **人数上限**：一局中可出现的冤罪师数量上限。
- **栽赃内鬼后与其一同获胜**：开启后，冤罪师栽赃内鬼时可以与该内鬼一起获胜；关闭后不会与内鬼共同获胜。

## Innocent

The Innocent can use the kill button to frame any player. The framed target immediately kills the Innocent. The Innocent wins if the target is voted out in a meeting; if the target is an Impostor, this win requires the corresponding setting.

The Jester, Executioner, and Innocent can win together.

## Settings

- **Maximum number:** Maximum number of Innocents in a match.
- **Win with framed Impostor:** When enabled, the Innocent and an Impostor win together if the Innocent framed that Impostor.
