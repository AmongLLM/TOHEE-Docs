## Cloud 网页标签

登录 TOHEE Cloud 并绑定游戏账号后，可以在网页上设置自己的标签文字和颜色。

查看[Cloud 标签教程](/docs/cloud-tags)，了解如何设置和刷新标签。

## 房主本地标签

房主可以在 `TOHEE-DATA/Tags/` 中为玩家配置标签、命令权限和 GM 身份，用于自己开设的房间。

查看[本地标签与权限](/docs/guide-local-tags)，使用生成器制作文件，或按示例手动编辑。

<!-- en -->
## Cloud web tags

Sign in to TOHEE Cloud and link your game account to set your own tag text and colour on the website.

See [Cloud tags](/docs/cloud-tags) to learn how to set and refresh your tag.

## Host-local tags

Hosts can configure player tags, command access and GM status in `TOHEE-DATA/Tags/` for the rooms they host.

See [Local tags and permissions](/docs/guide-local-tags) to create a file with the generator or edit one using the example.
