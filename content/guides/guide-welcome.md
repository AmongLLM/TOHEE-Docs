## TOHEE 是什么？

Town of Host: Enhanced-Enhanced（TOHEE）是 Among Us 的房主专属模组。房主在 Windows 电脑上运行模组并控制房间规则；其他玩家通常可以使用未修改的游戏客户端加入。TOHEE 提供角色、阵营、游戏模式和房间选项，具体内容以当前发行版为准。

TOHEE 基于 Town of Host: Enhanced 上游项目发展。上游网站的旧教程可能使用不同的安装包、设置文件和操作步骤；本文档已按当前 TOHEE 行为整理。安装请从 [TOHEE GitHub Releases](https://github.com/Niko-s-Impostor-Server/TownofHost-Enhanced-Enhanced/releases) 获取与游戏平台和架构匹配的发行包。

- [设置房间](/docs/guide-setup)，了解游戏、系统和模组设置。
- [游戏模式](/docs/guide-game-modes)介绍当前标准模式（Standard）、自由混战（FFA）与 TOHE 躲猫猫模式，以及上游历史模式。
- [命令与快捷键](/docs/guide-features)、[预设](/docs/guide-presets)和[聊天模板](/docs/guide-templates)可帮助你管理房间。
- 若要使用 Cloud 账号、绑定游戏账号或设置 Cloud 玩家标签，请看[TOHEE Cloud 指南](/docs/cloud-overview)。
- 在客户端调整内置技能音效，详见[自定义音效管理界面](/docs/guide-custom-sounds)；模组内的 Cloud 按钮详见[Cloud 界面使用方法](/docs/cloud-client-menu)。

只有房主需要安装模组。加入房间的玩家仍须使用与房主兼容的 Among Us 游戏版本；手机、平板和主机玩家不能安装此 Windows 模组，但可按游戏支持情况加入房间。

## What is TOHEE?

Town of Host: Enhanced-Enhanced (TOHEE) is a host-only Among Us mod. The host runs the mod on a Windows PC and controls the room rules; other players can usually join with unmodified game clients. TOHEE adds roles, factions, game modes, and room options. The current release determines what is available.

TOHEE builds on the upstream Town of Host: Enhanced project. Older upstream pages may describe different packages, settings files, and procedures; this documentation has been updated for current TOHEE behavior. Get the release that matches your game platform and architecture from [TOHEE GitHub Releases](https://github.com/Niko-s-Impostor-Server/TownofHost-Enhanced-Enhanced/releases).

## Start here

- [Install the mod](/docs/guide-installation), then read [how to update it](/docs/guide-updating).
- [Set up a room](/docs/guide-setup) with the game, system, and mod settings.
- [Game modes](/docs/guide-game-modes) covers current Standard, FFA, and TOHE Hide & Seek, plus a historical upstream mode.
- Use [commands and hotkeys](/docs/guide-features), [presets](/docs/guide-presets), and [chat templates](/docs/guide-templates) to manage your room.
- For Cloud accounts, linked game accounts, or Cloud player tags, see the [TOHEE Cloud guide](/docs/cloud-overview).
- Adjust built-in ability effects in the [Custom Sound Manager](/docs/guide-custom-sounds), and learn the mod's Cloud buttons in [the in-mod Cloud interface guide](/docs/cloud-client-menu).

Only the host needs to install the mod. Joining players still need an Among Us game version compatible with the host; mobile, tablet, and console players cannot install this Windows mod, but may join a room where the game supports it.
