## Cloud 能做什么

TOHEE Cloud 是模组的配套玩家服务。一个 Cloud 账号可以绑定多个 Among Us 账号，每个游戏账号分别设置玩家标签和房间分享。阅读模组文档不需要登录。

| 功能 | 用途 | 从哪里开始 |
| --- | --- | --- |
| 游戏账号 | 验证并管理你拥有的 Among Us 账号 | [绑定指南](/docs/cloud-accounts) |
| 免费玩家标签 | 配置游戏中显示的文字和颜色 | [标签指南](/docs/cloud-tags) |
| 分享房间 | 让符合资格的用户找到你的房间 | [分享指南](/docs/cloud-sharing) |
| 查找房间 | 筛选房间并复制房间码 | [匹配指南](/docs/cloud-rooms) |

## 第一次使用

完整的 Cloud policy（信息收集协议）未包含在模组内；注册或登录 Cloud 时，在网页阅读并同意后继续。模组面板的提示不替代协议。面板使用方法见[模组内 Cloud 界面](/docs/cloud-client-menu)。

1. 在 [注册页面](/register) 使用邮箱注册，或在 [登录页面](/login) 使用 Discord 登录。先阅读并接受信息收集协议。
2. 邮箱注册需要接收一次性验证码，并设置至少 10 位的密码。验证码只能使用一次，10 分钟后过期。
3. 如果 Discord 首次登录后提示设置 Cloud 密码，先到“账号设置”完成设置；若管理员重置了密码，则先更改临时密码。
4. 在“绑定 Among Us 账号”中选择从模组绑定或好友请求验证。
5. 绑定完成后，到“玩家标签”设置文字和颜色；需要分享房间时，再分别开启网站和模组的分享开关。

## Cloud 账号与游戏账号

Cloud 登录与 Among Us 登录是两件事。登录 Cloud 不会自动证明你拥有某个游戏账号；绑定时还需要在模组或游戏中完成验证。你无需把 Among Us 密码填写到 Cloud。

邮箱、Discord 是 Cloud 的登录方式，绑定的 Among Us 账号是被管理的游戏身份。解绑某个游戏账号不会解除 Cloud 的邮箱或 Discord 登录方式。

## 遇到问题

安全验证、邮件、Discord 登录或好友验证不可用时，按页面提示稍后重试。服务暂时不可用与账号验证未通过是不同情况，不能靠反复提交解决所有问题。详见 [Cloud 常见问题](/docs/cloud-help)。

## What Cloud offers

TOHEE Cloud is the mod's companion player service. Link several Among Us accounts to one Cloud account and manage each account's tag and room-sharing preference separately. Reading mod documentation does not require signing in.

| Feature | Purpose | Start here |
| --- | --- | --- |
| Game accounts | Verify and manage Among Us accounts you own | [Linking guide](/docs/cloud-accounts) |
| Free player tags | Set the text and colour displayed in game | [Tag guide](/docs/cloud-tags) |
| Room sharing | Help eligible users discover your room | [Sharing guide](/docs/cloud-sharing) |
| Find a room | Filter rooms and copy a room code | [Matchmaking guide](/docs/cloud-rooms) |

## First-time setup

The full Cloud policy is not included in the mod. Read and accept it on the website when registering or signing in to Cloud; the mod panel's notice does not replace the agreement. See [the in-mod Cloud interface](/docs/cloud-client-menu) for panel instructions.

1. [Register with email](/register), or use Discord on the [sign-in page](/login). Read and accept the information collection policy first.
2. Email registration requires a one-time code and a password of at least 10 characters. The code can be used once and expires after 10 minutes.
3. If your first Discord sign-in asks you to set a Cloud password, complete that step in Account settings. If an administrator reset your password, change the temporary password first.
4. Under Link an Among Us account, choose linking from the mod or friend request verification.
5. After linking, set your text and colour under Player tags. To share a room, enable sharing on both the website and the mod.

## Cloud accounts and game accounts

Cloud sign-in and Among Us sign-in are separate. Signing in to Cloud does not automatically prove ownership of a game account; linking requires verification in the mod or game. You do not need to enter your Among Us password into Cloud.

Email and Discord are Cloud sign-in methods. Linked Among Us accounts are the game identities you manage. Unlinking a game account does not unlink your Cloud email or Discord sign-in method.

## When something goes wrong

If security checks, email, Discord sign-in or friend verification are unavailable, follow the page's guidance and try again later. A temporarily unavailable service is different from rejected account verification; repeated submissions cannot solve every problem. See [Cloud troubleshooting](/docs/cloud-help).
