## 职业能力

时间之主使用通风口标记所有玩家的位置。再次使用能力时，所有存活玩家都会回到标记的位置。技能持续期间，时间之主获得可保护自己免于死亡的时间护盾。

## 设置

- **数量上限**：设置一局中时间之主的最大人数。
- **时间护盾冷却**：设置再次使用能力前的等待时间。
- **时间护盾持续时间**：设置护盾可以维持多久。
- **初始技能次数上限**：设置时间之主开局拥有的技能次数。
- **每完成一个任务获得的技能次数**：设置每完成一个任务增加的次数，按 0.1 为步进。

<!-- en -->
## Role

The Time Master uses vents to mark everyone's position. When they use the ability again, every living player is rewound to the marked position. During the ability duration, the Time Master gains a time shield that protects them from death.

## Settings

- **Maximum count**: Sets the maximum number of Time Masters in a match.
- **Time shield cooldown**: Sets how long the Time Master must wait before using the ability.
- **Time shield duration**: Sets how long the shield lasts.
- **Initial maximum ability uses**: Sets how many uses the Time Master starts with.
- **Ability uses gained per task**: Sets the uses gained for each completed task, in 0.1 increments.
